# Prompt Review Rule

**MANDATORY**: Before beginning ANY task from the user, you MUST:

1. **Read and summarize** the user's request back to them in an organized list
2. **Ask at least 2 clarifying questions** about the request before writing any code or making any changes
3. **Wait for the user's responses** before proceeding with implementation

This applies to EVERY prompt, no matter how simple or clear it seems. The goal is to ensure alignment and avoid wasted effort from misunderstandings.
